Pesquisa

1.1 Conexão

Como C# realiza uma conexão com um banco de dados?

--C# utiliza uma biblioteca ou driver para se comunicar com o banco de dados. O programa cria um objeto de conexão (no nosso projeto, MySqlConnection), informa a string de conexão e chama o método Open() para abrir a conexão. Depois de executar os comandos, a conexão é fechada (no projeto, isso é feito automaticamente pelo bloco "using").

Qual biblioteca/driver é utilizado pelo banco escolhido?

--O banco escolhido foi o MySQL e o driver utilizado no projeto é o MySqlConnector (pacote NuGet "MySqlConnector"). Ele é usado com a linha "using MySqlConnector;" e fornece as classes MySqlConnection (abre a conexão), MySqlCommand (executa o comando SQL) e MySqlDataReader (lê os resultados do SELECT).

Como essa biblioteca é adicionada ao projeto?

--A biblioteca é adicionada pelo NuGet (gerenciador de pacotes para projetos .NET) através do comando:

--dotnet add package MySqlConnector

--Esse comando registra o pacote MySqlConnector no arquivo .csproj do projeto. Depois, o comando "dotnet restore" baixa o pacote para quem clonar o repositório.

O que é uma string de conexão?

--É uma sequência de informações que indica ao programa como acessar o banco de dados.

Quais informações aparecem em uma string de conexão?

--Normalmente aparecem informações como servidor, nome do banco de dados, usuário, senha e, em alguns casos, a porta.

--A string de conexão do nosso projeto, usando o driver MySqlConnector, é:

--Server=localhost;Database=Jogos;User Id=root;Password=Senac2026;

---

1.2 Comandos SQL

Os comandos SQL são executados pelo C# usando o driver MySqlConnector: cria-se um MySqlCommand com o texto do SQL e a conexão aberta, passam-se os valores por parâmetros e executa-se o comando.

* INSERT: adiciona dados ao banco. No C#, usa-se o método ExecuteNonQuery(), que devolve a quantidade de linhas afetadas.

  string sql = "INSERT INTO jogo (nome, franquia, genero_principal, data_lancamento, nota) VALUES (@nome, @franquia, @genero, @data_lancamento, @nota)";

* SELECT: consulta dados. No C#, usa-se o método ExecuteReader(), que devolve um MySqlDataReader para percorrer as linhas.

  string sql = "SELECT * FROM jogo";

* UPDATE: altera dados existentes. No C#, usa-se o ExecuteNonQuery().

  string sql = "UPDATE jogo SET nome = @valor WHERE id = @id";

* DELETE: exclui dados. No C#, usa-se o ExecuteNonQuery().

  string sql = "DELETE FROM jogo WHERE id = @id";

---

1.3 Consulta de dados

O C# recebe os resultados de um comando SELECT através de um leitor, o MySqlDataReader (classe do driver MySqlConnector), obtido com o método ExecuteReader().

Os resultados podem ser percorridos linha por linha com um laço while, usando o método Read(), que avança para a próxima linha e retorna false quando os dados acabam. Os valores de cada coluna são lidos pelo nome, por exemplo leitor["nome"].

Em cada linha lida, é criado um objeto da classe (no projeto, Jogo_MySql) com os dados da linha, e os objetos são guardados em uma lista (List<Jogo_MySql>). Assim, os dados do banco podem ser utilizados dentro do sistema como objetos.

---

1.4 Segurança

Os parâmetros SQL permitem enviar os valores separadamente do comando SQL. No MySqlConnector, usa-se comando.Parameters.AddWithValue("@nome", valor). Eles ajudam a evitar SQL Injection (injeção de SQL).

SQL Injection (injeção de SQL) é um tipo de ataque no qual uma pessoa insere comandos SQL maliciosos em campos de um sistema para tentar acessar, alterar ou excluir dados do banco.

Quando o sistema coloca diretamente os textos digitados pelo usuário dentro de um comando SQL, ele pode ficar vulnerável a esse tipo de ataque.

Por isso, é recomendado utilizar comandos SQL parametrizados, como fazemos em todo o projeto.
